# blinktree (retired)

This personal link page is **retired**. Projects and social profiles now live on **[barrett.software](https://barrett.software/)**.

GitHub Pages cannot emit an HTTP 301 from this repo (no custom domain). The published page uses a meta refresh plus `location.replace` to send visitors there, with a visible fallback link.

The original open-source link-in-bio template remains in git history if you want to fork it.
